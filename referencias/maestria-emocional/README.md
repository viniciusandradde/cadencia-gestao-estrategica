# Maestria Emocional: homens e mulheres (Jornada EVO)

> **Aviso.** Material de curso pago de terceiros (Márcio Micheli, Jornada EVO Presencial), mantido aqui **só para uso pessoal, em repositório privado**. Não publicar nem compartilhar.

Esta pasta reúne as duas versões do curso para a **junção** que será feita aqui: **homens** (módulo 8 do Drive, 115 aulas, ~19,7 h) e **mulheres** (módulo 9, 110 aulas, ~19,9 h). Ambas têm os módulos 00 (introdutório) a 11.

| Pasta | Conteúdo |
|---|---|
| `homens/transcricoes/` | uma transcrição por módulo (12 arquivos) |
| `mulheres/transcricoes/` | uma transcrição por módulo (12 arquivos) |
| `*/manifesto-aulas.csv` | lista de aulas com duração |

Observações: a transcrição é automática (Whisper), com erros possíveis em nomes e termos; os arquivos do Drive não trazem título de aula, só "Aula N". O nome do autor na fala aparece como "Márcio Michele"; neste repositório usa-se "Micheli". Transcrições completas por aula, EPUB e scripts estão no acervo `vsa-formacao`.

Ainda **não há fichas de metodologia** desta pasta (a mescla entre homens e mulheres vem depois).
